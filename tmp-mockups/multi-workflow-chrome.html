A1 — Session dropdown

Chosen multi-workflow chrome. Open sessions switch in the dropdown; saved workflows list below a separator and open as independent copies (not linked to the library row). No Comfy status in the bar — connection / convert problems use app notifications.

Behavior
  • Open from image / Comfy adds a new open session from outside.
  • Picking a saved workflow opens a copy with that name. It is not linked to the saved id. Save always goes through the name dialog.
  • If that name is already used by an open session, the new one becomes Name (2), Name (3), …
  • Save dialog pre-fills the session name. If it matches an existing saved workflow, show an overwrite warning under the field.
  • No dirty indicators (dots / Save*). Seeds and other controls change constantly; a dirty flag would almost always be on.
  • Saved rows can be deleted from the menu (×). Deleting a saved workflow does not close open sessions that were copied from it.
  • 0 open sessions: placeholder trigger, empty body, Save/JSON/Generate disabled. Saved list still available in the menu.
