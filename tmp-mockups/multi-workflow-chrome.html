Multi-workflow chrome

Mockups for keeping several workflows open in the Generate panel. Most of the time the panel is narrow (~340px); a wider ~620px view is shown where it changes the story. Today’s name field eats the first row — several options reclaim that space.

Fits narrowA. Session dropdown (replaces name field)

Current workflow is chosen from a dropdown that lists open sessions. No inline name field — Save opens a dialog for the real name (first save or Save As). Load… still pulls from saved library into a new/replaced session.

Narrow ~340pxname field gone
Wider ~620pxsame chrome, more body
  • Best density: one control does “what’s open” + switch.
  • Dirty indicator as a small dot; count badge (3) shows how many are open.
  • Menu actions: switch, close, New, Open from library…
  • Tradeoff: switching costs a click; names truncated in the trigger.

FamiliarB. Compact tabs

Browser-style tabs under (or instead of) part of the toolbar. Horizontal scroll when many tabs; close on the tab; + to open another. Name field dropped — title lives on the tab; Save still uses a dialog when untitled.

Narrowtabs scroll
Widermore tab labels visible
  • Instant visual of what’s open; one-click switch.
  • On 340px, 3+ tabs get cramped — scroll or overflow menu needed.
  • Steals a full row of vertical space (~32px).

CompactC. Pill / chip strip

Same idea as tabs, but lighter: a single thin row of pills under the action buttons. Scrolls horizontally; active chip is accented. Less “browser chrome,” slightly shorter than tabs.

Narrow
Wider
  • Cheaper vertically than full tabs; still scannable.
  • Close affordance is weaker (long-press / × in menu) unless each chip has an ×.

Needs widthD. Side session list

Narrow: collapses to a “Sessions” toggle that overlays or expands. Wide: fixed left rail (~120px) listing open workflows. Body keeps full toolbar without the name field.

Narrow — list hidden, toggle in bar
Wider — persistent list
  • Great when the panel is often wide; awkward as the default narrow case.
  • Long names fare better than tabs/chips.

Minimal chromeE. “Windows” button + inline title

Keep a one-line title (read-only, truncated) and a Windows/Sessions button that opens the full list. Closest to today’s single-row density; multi-open is “hidden” until you need it.

Narrow
Wider
  • Almost zero new permanent UI vs today.
  • Discoverability is weaker — people may not realize multiple can stay open.

F. Current + recents jump row

No full session manager in the chrome. Show current name plus 1–2 recently used open sessions as text links. Overflow goes into a small menu. Hybrid between single-session habits and multi-open.

Narrow
Wider
  • Lightest visual change; doesn’t scale past ~3–4 sessions well.
  • Ambiguous whether “recent” means open sessions or library history.
